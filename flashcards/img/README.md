# 字卡圖片資料夾

檔名 = 單字，**一律小寫**（GitHub Pages 區分大小寫，大寫會抓不到圖）。
片語用減號接，例如 `good-morning.jpg`。網頁重整就自動抓，不用改程式。
沒放的字會用預設 emoji，不會壞掉。

`_source/` 是你拍的整組原始照片，裁切用的，網頁不會讀。
上傳 GitHub 時可以把它加進 .gitignore 不帶上去。

## 以後老師發新字卡

1. 一組拍一張照片（整排一起拍沒關係）
2. 丟進這個資料夾
3. 跟 Claude 說「img 裡有新照片」，它會看圖認卡、裁切、命名、寫進程式
