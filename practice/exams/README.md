# 考卷照片放這裡

## 用法
1. 哥哥的考卷、習作、電子書印出來的練習卷，寫完之後拍照丟進這個資料夾
   - **整張拍就好**，不用裁切
   - 有寫錯的地方不用擦掉，錯題正是重點
2. 跟 Claude 說一聲：「exams 裡有新考卷」
3. Claude 會看題目、找出他錯在哪個觀念，產生一份「舉一反三」的練習單，
   放進 `../quizzes/`，哥哥在平板上就能直接寫

## 檔名
隨便取沒關係，Claude 會看圖認內容。
但如果你方便，用 `日期-科目` 會比較好找，例如 `1120-數學.jpg`。

## 可以順便跟 Claude 說的事
- 這張是第幾單元 / 第幾課
- 哪幾題他寫錯了（Claude 自己也看得出來，但你知道的話更準）
- 想要幾題、偏重哪個觀念
